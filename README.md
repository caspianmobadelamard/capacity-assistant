# Capacity Assistant | دستیار تعیین ظرفیت

برنامه مشاوره تخصصی تعیین ظرفیت تجهیزات تاسیساتی برای **کاسپین مبدل آمارد**.

## 🚀 قابلیت‌ها

- محاسبه دیگ بخار (Fulton)
- محاسبه دیگ آبگرم/آب‌داغ (ASHRAE Fixture-based)
- محاسبه بار گرمایش (شوفاژ)
- محاسبه گلخانه، استخر، سونا
- محاسبه تجهیزات جانبی: سختی‌گیر، دی‌اریتور، منبع کندانس، منبع انبساط، فیلتر شنی
- نمایش فرمول هر محاسبه با مرجع
- انتخاب ضریب اطمینان (1.2، 1.3، 1.35)
- الگوی مصرف پیوسته/پیک‌دار
- تفکیک کامل حوزه بخار و آبگرم

## 📱 نصب

### PWA (همه سیستم‌عامل‌ها)
1. فایل‌ها را روی یک سرور وب قرار دهید (یا از GitHub Pages استفاده کنید)
2. در مرورگر موبایل باز کنید
3. گزینه "Add to Home Screen" را بزنید

### Android (APK)
از [PWABuilder](https://www.pwabuilder.com/) برای تبدیل به APK استفاده کنید.

### Windows (EXE)
از Electron یا PWABuilder استفاده کنید.

### iOS
از Safari گزینه "Add to Home Screen" را انتخاب کنید.
